# 🏦 LifeSimulator (Versão 1.0.0)

Este é o meu primeiro projeto prático de programação: um simulador financeiro e de vida. O objetivo do sistema é criar um ambiente onde é possível gerenciar um saldo inicial, subtrair despesas fixas (como luz, água e internet) e adicionar rendimentos extras, tudo rodando pelo terminal.

### ☕ Por que escolhi o Java?
Dentre todas as linguagens de programação disponíveis, escolhi o **Java** para ser o motor deste sistema. Após avaliar algumas opções, o Java se mostrou a ferramenta mais **cabível** para este cenário. 

A sua tipagem forte, a rigidez com que trata variáveis matemáticas (como o uso do `double` para centavos) e a sua organização estrutural me deram a segurança necessária para garantir que a lógica financeira funcionasse de forma impecável, sem brechas para erros de cálculo.

### ⚙️ O que o sistema já faz (v 1.0.0):
* Definição de saldo inicial em banco.
* Pagamento automático de contas fixas pré-definidas.
* Atualização em tempo real do saldo em caixa.
* Impressão formatada e concatenada de resultados no terminal.
